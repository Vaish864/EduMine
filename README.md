# EduMine

## Student Feedback Text Mining and Opinion Analysis System

EduMine is a web-based Text Data Mining application that analyzes student feedback to identify sentiment, frequently discussed topics, keywords, and useful patterns in student opinions.

### Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite
- Data Mining: Python, NLTK, Scikit-learn, MLxtend
- Visualization: Chart.js
- Data Mining Tool: Orange Data Mining
